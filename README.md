# FinLLM-Temporal-Shift
A leakage-controlled framework for evaluating temporal robustness and diagnosing out-of-time failures in financial LLMs.

# FinGPT Temporal Generalization

Research notebooks for the finalized FinGPT temporal-generalization study.

The main line is Day14–Day17 and Day22–Day27. It proceeds from temporal benchmark construction through historical training, future evaluation, historical-only optimization controls, residual F3 diagnosis, and the out-of-time lexical-instability hypothesis test.

Run notebooks from the repository root or its `notebooks/` directory. Project paths are discovered from this README and preserve the existing `data/`, `results/`, and `models/` hierarchy. Existing upstream artifacts from earlier days are required. Model notebooks retain their original dependency installation and hardware requirements.
